#6.Java Comments
Sirven para dejar notas aclaratorias en el código que el compilador ignora automáticamente. Se usan con // para una línea o /* */ para varias líneas.

#7.Java Variables
Son contenedores para almacenar datos y valores. Se declaran indicando el tipo de dato y un nombre (por ejemplo: int edad = 18;).

#8.Java Data Types
Definen el tipo de valor que puede almacenar una variable, dividiéndose en primitivos (como int, double, char) y de referencia.

#9.Java Type Casting
Es el proceso de convertir un tipo de dato en otro diferente (por ejemplo, transformar un número entero int a un decimal double).

#10.Java Operators
Símbolos utilizados para realizar operaciones sobre variables y valores, tales como aritméticos (+, -, *, /) o de comparación (>, <).

#11.Java Strings
Se utilizan para almacenar y manipular cadenas de texto. Sus valores siempre van escritos entre comillas dobles (por ejemplo: String texto = "Hola";).

#12.Java Math
Clase de Java que ofrece métodos avanzados para realizar operaciones matemáticas, como calcular valores máximos, mínimos, potencias o raíces.

#13.Java Booleans
Tipo de dato lógico que solo puede almacenar dos posibles valores: verdadero (true) o falso (false), ideales para condiciones.
